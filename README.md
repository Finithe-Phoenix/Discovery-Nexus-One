# NEXUS ONE

**Centro de Control Empresarial Multioperador**

Demo ejecutiva e interactiva para concentrar la administración de SIM, eSIM, inventario, red de distribución, monederos, crédito, ventas, activaciones, comisiones y auditoría de Movistar, AT&T, Bait y otros operadores.

## Alcance demostrado

- Tres perfiles: Dirección y Matriz, Distribuidor/Subdistribuidor y Punto de Venta.
- Vista consolidada y universos independientes por operador.
- Inventario y trazabilidad por ICCID.
- Ventas, activaciones, eSIM, monedero, crédito y comisiones.
- Tableros, inteligencia operativa y auditoría.
- PWA instalable y responsiva para escritorio, tableta y teléfono.

## Exclusiones deliberadas

No incluye tienda en línea, portal de consumidor final, WhatsApp Business ni aplicaciones nativas Android/iOS. Todos los datos son simulados y no existen conexiones productivas.

## Publicación

El workflow `.github/workflows/pages.yml` valida y despliega el contenido con GitHub Pages. En la configuración del repositorio, Pages debe usar **GitHub Actions** como origen de publicación.
